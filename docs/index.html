curl -fsSL "https://raw.githubusercontent.com/shostwp-byte/spanel/refs/heads/main/install.sh?v=$(date +%s)" -o /tmp/spanel-install.sh && sudo env npm_config_legacy_peer_deps=true bash /tmp/spanel-install.sh

2. Danh mục 10 Nhóm Tính năng Toàn diện

👥 1. Phân quyền 3 Cấp độ & Access Role Switch

  • 3 Vai trò độc lập: Admin (Quản trị máy chủ), Reseller (Đại lý hosting kèm White-Label Branding), End User (Khách hàng cuối).
  • Access Role Switch & Impersonation: Chuyển đổi nhanh góc nhìn Admin / Reseller / User ngay trên thanh Topbar hoặc đăng nhập thay thế 1-Click (Login as / Return to).
  • Kiểm toán & Chuyển quyền sở hữu (Owner Transfer): Tự động cảnh báo và hỗ trợ chuyển giao Website/Database tạo nhầm dưới tài khoản Admin/Reseller sang đúng tài khoản End User.

🌐 2. Quản trị Tên miền, Subdomain, Redirects & SSL/TLS

  • Domain Setup (/website): Thêm tên miền, đổi tên miền (Rename Domain), chọn phiên bản PHP riêng (5.6 – 8.5), bật/tắt Force SSL, Open_basedir, FastCGI Cache, quản lý Domain Aliases & Pointers.
  • Subdomains, Redirects & Handlers: Tạo Subdomain chuẩn hóa tiền tố, thiết lập chuyển hướng 301/302 và cấu hình MIME/Apache Handlers.
  • SSL/TLS Toàn diện: Let's Encrypt HTTP-01, Wildcard SSL qua Cloudflare DNS-01, Shared/Cloudflare Origin SSL, Custom Certificate và Server TLS cho cổng Panel/Mail.

⚡ 3. WordPress Manager Chuyên sâu (WP-CLI & 1-Click)

  • Nhận diện & 1-Click SSO: Tự động phát hiện cài đặt WordPress ở cả thư mục gốc và thư mục con (/blog, /shop); đăng nhập thẳng wp-admin không cần mật khẩu.
  • Quản lý Core, Plugins, Themes & Users: Cập nhật, kích hoạt, gỡ bỏ trực tiếp trên giao diện SPanel.
  • Gia cố Bảo mật 1-Click: Block PHP in Uploads (chặn thực thi .php/.phtml/.phar ở cả Nginx vhost và .htaccess), Disable XML-RPC, DISALLOW_FILE_EDIT, Hide WP Version, Maintenance Mode, Redis Object Cache & System Cron.
  • Snapshot & Clone WordPress: Chụp nhanh mã nguồn + DB .sql.gz; nhân bản sang tên miền khác kèm chống tấn công symlink/hardlink/UID spoofing.

🔧 4. Đa phiên bản PHP (5.6 – 8.5), CustomBuild & Smart PHP Guard

  • Multi-PHP Song song: Hỗ trợ đầy đủ PHP 5.6, 7.4, 8.0, 8.1, 8.2, 8.3, 8.4 và 8.5 với pool PHP-FPM độc lập cho từng website.
  • CustomBuild & Smart PHP Guard: Cài đặt/gỡ bỏ nhánh PHP, quản lý Extensions, sửa php.ini và tự động vá lỗi bảo mật PHP không gián đoạn dịch vụ (Zero-Downtime Reload).
  • Auto-Tuning & Custom HTTPD: Tự động tối ưu pm.max_children và innodb_buffer_pool_size theo RAM thực tế; kiểm tra nginx -t trước khi áp dụng cấu hình Nginx tùy chỉnh.

🗄️ 5. MariaDB, Remote MySQL, MySQL Governor & phpMyAdmin SSO

  • MariaDB Nội bộ & Remote MySQL: Quản lý database trên máy chủ nội bộ hoặc cụm MySQL/MariaDB từ xa qua kết nối TLS xác thực chứng chỉ CA (giới hạn chặt chẽ IP kết nối).
  • 1-Click phpMyAdmin SSO: Đăng nhập thẳng vào phpMyAdmin bằng token một lần có hiệu lực 60 giây.
  • Safe SQL Import / Export: Tự động lọc bỏ mệnh đề DEFINER= và từ chối các câu lệnh đặc quyền (GRANT, SUPER, SET GLOBAL) khi nạp file .sql/.sql.gz; tuyệt đối không fallback sang quyền root.
  • MySQL Governor: Giới hạn truy vấn/giờ, kết nối/giờ và tự động khóa ghi (write_locked) khi vượt hạn mức dung lượng DB.

📊 6. Cô lập Tài nguyên Cgroups v2 & Giám sát Thời gian thực

  • Giới hạn Cgroups v2 theo Gói & User: Kiểm soát cứng cpu_quota_percent, memory_high_mb, memory_max_mb, băng thông đọc/ghi đĩa (io_read_mbps, io_write_mbps), IOPS và tổng số tiến trình (tasks_max).
  • Resource Monitor & Process Monitor: Theo dõi biểu đồ CPU, RAM, Disk I/O, Network, Inodes và danh sách tiến trình theo thời gian thực; tự động phát hiện tài khoản bị tấn công (Under Attack).

💾 7. Trung tâm Sao lưu 5 Phân khu, Granular Restore & Migration

  • 5 Phân khu Chuyên biệt: User Backups, Website Backups, Scheduled Backups (Full/Incremental + Retention), Panel Self-Backup & Verification và Restore & Destinations (Local, SFTP/FTP, AWS S3 / Cloudflare R2 / MinIO).
  • Khôi phục Chi tiết (Granular Restore): Chọn khôi phục toàn bộ (Web + DB + Email) hoặc từng phần riêng lẻ kèm xác thực mã băm SHA-256.
  • Panel Migration: Nhập trực tiếp gói sao lưu từ DirectAdmin (.tar.zst, .tar.gz) và cPanel (cpmove-*.tar.gz).

🛡️ 8. Tường lửa Chủ động, WAF ModSecurity, Fail2ban & Quét Mã độc

  • Tường lửa iptables + ipset: Quản lý cổng, chặn IP/CIDR tức thì và nạp danh sách đen (IP Blocklist URLs) hàng trăm nghìn IP với độ trễ bằng 0.
  • WAF ModSecurity + OWASP CRS & HTTP Flood: Bảo vệ từng website khỏi SQLi/XSS/LFI, chặn Bad Bots toàn cục và giới hạn tốc độ kết nối chống DDoS tầng 7.
  • Brute Force Monitor & Malware Scanner: Tích hợp Fail2ban khóa IP dò mật khẩu và quét mã độc bằng LMD + ClamAV (theo yêu cầu, theo lịch và thời gian thực).

🔔 9. Hệ thống Thông báo Đa kênh (System Notifications)

  • Chuông Thông báo Phân tầng: Tự động lọc cảnh báo theo cấp độ quyền hạn hiện tại (Admin Level, Reseller Level, User Level).
  • Giao diện 3 Tab trực quan cho Admin:
    • General: Cấu hình chi tiết các sự kiện cảnh báo hạ tầng máy chủ và bảo mật tài khoản.
    • Channels: Kết nối SMTP Email, Telegram Bot và Custom Webhooks (ký xác thực HMAC-SHA256).
    • Delivery log: Nhật ký trạng thái gửi và tự động thử lại (Retry) khi kênh đích gián đoạn.

🧩 10. Hệ sinh thái Add-ons, Multi-Server, WHMCS & MCP AI

  • Add-ons Đồng bộ Menu: Application (Node.js, Python, Docker, Docker Compose), Email Server Suite (Exim4, Dovecot, Rspamd, Webmail SSO cổng 2096), DNS Management (PowerDNS cổng 53) và Demo Mode.
  • Multi-Server Cluster: Kiểm tra xung đột tên miền/DNS xuyên cụm máy chủ và điều phối Remote MySQL.
  • WHMCS & MCP Server: Module WHMCS có sẵn tại modules/servers/spanel/ và giao thức MCP kết nối Claude Code, Cursor, VS Code.

5. Yêu cầu Hệ thống, Cài đặt & Cập nhật Trực tuyến

💻 Yêu cầu Hệ thống

  • Hệ điều hành: Ubuntu 24.04 LTS (64-bit, cài mới).
  • Cấu hình tối thiểu: 1 vCPU / 1 GB RAM / 20 GB SSD.
  • Cấu hình khuyến nghị: Từ 2+ vCPU / 2 – 4+ GB RAM / 40+ GB NVMe SSD (đặc biệt khi bật Rspamd hoặc ClamAV).
  • Quyền truy cập: root hoặc sudo.

🚀 Cài đặt Tự động (Unattended)

Thực thi bằng quyền root trên máy chủ Ubuntu 24.04 LTS:

curl -fsSL "https://raw.githubusercontent.com/shostwp-byte/spanel/refs/heads/main/install.sh?v=$(date +%s)" | sudo env npm_config_legacy_peer_deps=true bash -s -- \
  --admin-user admin \
  --admin-pass 'MatKhauManh@2026!' \
  --php-default 8.4

🔄 Cập nhật Trực tuyến (Zero-Downtime Update)

Thực hiện trực tiếp trên giao diện Server Manager → Maintenance / Panel Updates hoặc qua SSH:

sudo spanel-update

Tự động sao lưu spanel.db trước khi cập nhật, chạy migration Alembic, kiểm tra dấu vân tay (fingerprint) gói Frontend và tự động rollback nếu phát sinh lỗi.

7. Giới hạn đã biết (Known Limitations)

  • Kiến trúc Điều khiển Đơn điểm (Single-Node Control Plane): SPanel sử dụng SQLite ở chế độ WAL (busy_timeout=15000ms) cho cơ sở dữ liệu điều khiển (spanel.db). Thiết kế này tối ưu cho một máy chủ VPS/Dedicated độc lập (vận hành từ vài chục đến vài trăm website), không hướng tới mô hình cụm điều khiển đa điểm ghi đồng thời (multi-master control plane).
  • Cơ sở dữ liệu MySQL Từ xa (Remote MySQL): Quản trị viên cấu hình máy chủ MySQL/MariaDB từ xa trong Multi-Server → Remote MySQL để người dùng chọn khi tạo database mới, đổi mật khẩu, tải/nạp SQL, khóa ghi khi vượt hạn mức, sao lưu/khôi phục và đăng nhập phpMyAdmin SSO. Các database tạo tự động kèm luồng cài đặt nhanh WordPress 1-Click, WHMCS Provisioning hoặc nhập từ cPanel/DirectAdmin mặc định vẫn khởi tạo trên MariaDB nội bộ.
  • Hạn mức Ổ đĩa Tầng Kernel (setquota): Cưỡng chế dung lượng đĩa bằng lệnh setquota yêu cầu phân vùng /home hoặc / của máy chủ đã bật cờ mount usrquota / usrjquota. Trên các VPS chưa bật usrquota ở tầng filesystem, SPanel vẫn cưỡng chế đầy đủ hạn mức dung lượng ở tầng ứng dụng (File Manager, Upload, Giải nén, Khởi tạo Website, Sao lưu và MySQL Governor).
  • HTTP/3 (QUIC): Chỉ thị listen 443 quic reuseport và header Alt-Svc được kích hoạt tự động khi binary Nginx trên máy chủ có biên dịch module ngx_http_v3_module (như gói Nginx mainline từ nginx.org). Với gói Nginx mặc định của Ubuntu chưa bật module này, SPanel tự động phục vụ qua HTTP/2 + TLSv1.3.
