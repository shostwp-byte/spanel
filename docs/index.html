Bảng điều khiển Web Hosting Đa tầng cho Ubuntu 24.04 LTS

Quản trị toàn diện máy chủ với kiến trúc 3 cấp độ (Admin / Reseller / End User), giao diện quản lý Tên miền & Subdomain chuẩn DirectAdmin, bảo mật cô lập đặc quyền spanel-helper, tích hợp WHMCS và tối ưu hoàn hảo trên di động.

curl -fsSL https://raw.githubusercontent.com/shostwp-byte/spanel/refs/heads/main/install.sh -o /tmp/spanel-install.sh && sudo bash /tmp/spanel-install.sh

1. Các Nhóm Tính năng Cốt lõi

🌐 Quản lý Domains & Subdomains chuẩn DirectAdmin

  • Domain Setup (/website): Thêm tên miền mới, đổi tên miền (Rename Domain), bật/tắt Force SSL, chọn phiên bản PHP (5.6 – 8.5), bật/tắt Open_basedir và tuỳ chỉnh cột hiển thị (Columns ⌄).
  • Subdomain Management (/subdomains): Thanh chọn tên miền nhanh ở đầu trang, tạo Subdomain tự động chuẩn hoá tiền tố và tuỳ chỉnh Document Root.

👥 Kiến trúc Đa tầng Admin / Reseller / User

  • Admin: Quản trị toàn máy chủ, Resource & Process Monitor, IP Manager, Name Servers, Custom HTTPD, Server TLS, Packages, Add-ons & Panel Updates.
  • Reseller: Tạo & quản lý khách hàng thuộc đại lý, gói hosting riêng, White-Label Branding (Logo, Favicon, Tên Panel) và đổi mật khẩu hàng loạt.
  • End User: Giao diện quản trị trực quan, tự động ẩn các menu nếu Add-on chưa được Admin kích hoạt.

🛡️ Bảo mật Đa lớp & Cô lập Đặc quyền

  • Tiến trình spanel-api chạy dưới user spanel không quyền root; mọi tác vụ hệ thống đi qua spanel-helper kiểm duyệt chặt chẽ.
  • Tường lửa iptables + ipset hiệu năng cao kèm danh sách chặn IP tự động và Fail2ban.
  • WAF ModSecurity + OWASP CRS theo từng website, quét mã độc ClamAV + LMD, bảo mật 2FA TOTP & Passkey.

📬 Email, DNS, Backup & Di chuyển Dữ liệu

  • Email Suite: Exim4, Dovecot, Rspamd lọc thư rác, Forwarders, Autoresponders, DKIM/DMARC tự động và SPanel Webmail SSO (cổng 2096).
  • PowerDNS: Quản lý DNS Zone trực tiếp trên máy chủ (A, AAAA, CNAME, MX, TXT, SRV, CAA, NS).
  • Backup & Migration: Sao lưu tự động lên S3 / SFTP và nhập trực tiếp bản sao lưu từ DirectAdmin & cPanel.

🔔 Thông báo Phân loại & Giao diện Mobile

  • Phân luồng thông báo độc lập cho Admin, Reseller và End User kèm bộ lọc theo danh mục (Hệ thống, Bảo mật, Sao lưu, Tài nguyên).
  • Thiết kế Mobile Responsive tối ưu cho điện thoại (<= 640px) và máy tính bảng: bảng tự thu gọn cột phụ, hộp thoại cuộn mượt theo khung nhìn.

🔌 Tích hợp WHMCS & Trợ lý AI MCP

  • Module WHMCS có sẵn tại modules/servers/spanel/ hỗ trợ cấp phát, tạm khoá, nâng gói, đồng bộ dung lượng và đăng nhập 1-click (SSO).
  • Hỗ trợ giao thức MCP (Model Context Protocol) giúp kết nối Claude Code, Cursor, VS Code trực tiếp vào SPanel bằng token cá nhân.

3. Cài đặt & Cập nhật Nhanh trên VPS

🚀 Cài đặt Tự động (Unattended)

Chạy bằng quyền root trên máy chủ Ubuntu 24.04 LTS mới:

curl -fsSL https://raw.githubusercontent.com/shostwp-byte/spanel/refs/heads/main/install.sh | sudo bash -s -- \
  --admin-user admin \
  --admin-pass 'MatKhauManh@2026!' \
  --php-default 8.4

🔄 Cập nhật Phiên bản Mới (Online Update)

Cập nhật trực tiếp trong giao diện Admin → Cài đặt → Cập nhật hoặc chạy lệnh SSH:

sudo spanel-update

Bảo toàn 100% dữ liệu, cấu hình .env, tự động chạy migration DB và tự động rollback nếu gặp lỗi.

4. Các Lệnh Quản trị & Cứu hộ Thường dùng qua SSH

Lệnh thực thi Công dụng
sudo spanel Mở menu cứu hộ tương tác qua SSH (xem thông tin đăng nhập, khởi động lại dịch vụ, sửa quyền, cấp SSL).
sudo spanel change-admin-password Đặt lại mật khẩu đăng nhập cho tài khoản admin của SPanel.
sudo spanel change-ip <IP_CŨ> <IP_MỚI> Cập nhật địa chỉ IP máy chủ hàng loạt cho toàn bộ cấu hình Nginx vhost và DNS Zone.
sudo spanel-rescue-firewall Sao lưu luật tường lửa hiện tại và khôi phục bộ luật tối thiểu khi bị khoá ngoài máy chủ.
sudo spanel-update Kiểm tra và nâng cấp SPanel lên bản phát hành mới nhất từ kho GitHub.
